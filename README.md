# 🌿 Nasmah | نسمـــة

> **دليل الشركـات والمؤسسات المفتوح للجميع.**  
> A clean, bilingual (Arabic/English) modern company directory connecting talent with career pages and business links.

## 📌 Features | المميزات

- 🔍 **البحث:** إمكانية البحث بأسماء الشركات باللغتين العربية والإنجليزية وتصفيتها حسب القطاع.
- 🌐 **دعم كامل للغتين (i18n):** واجهة مستخدم سهلة التبديل بين العربية والإنجليزية.
- 💡 **تقديم الاقتراحات:** إمكانية اقتراح شركات جديدة مع إدخال روابط التوظيف والشبكات المهنية.
- ⚡ **أداء عالي وسريع:** مبني باستخدام FastAPI مع تقديم صفحة استجابة وتصميم معاصر.
- 🛡️ **معايير جودة عالية:** فحص آلي دائم للكود وشجرة جودة ممتازة (A Grade) في معايير Radon وRuff.

---

## 🏗️ Tech Stack | التقنيات المستخدمة

- **Backend:** Python 3.12, FastAPI, Uvicorn
- **Database:** SQLAlchemy ORM, SQLite (Plan for PostgreSQL migration in V2)
- **Frontend:** HTML5, Jinja2 Templates, Tailwind CSS
- **Code Quality & CI/CD:** GitHub Actions, Ruff Linter, Radon Metrics
- **Deployment:** Render (`nasmah.onrender.com`)
